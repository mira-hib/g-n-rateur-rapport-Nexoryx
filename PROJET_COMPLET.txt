🎯 OBJECTIF DU PROJET
────────────────────────────────────────────────────────────────────────────
Automatiser la génération de rapports d'audit de cybersécurité de haute
qualité pour résoudre les problèmes de cohérence, de détail technique et
d'actionabilité des rapports actuels de Nexoryx.

🏗️ ARCHITECTURE
────────────────────────────────────────────────────────────────────────────
Base de données SQLite
    ↓
Service d'extraction (typé)
    ↓
Workflow LangGraph (orchestrateur)
    ├── Agent Créateur → Génère les 8 sections avec enrichissement IA
    └── Agent Vérificateur → Valide la qualité (score 0-100)
    ↓
Boucle de correction (max 3 itérations)
    ↓
Assemblage du rapport complet
    ↓
Générateurs (PDF/DOCX)

📄 SECTIONS DU RAPPORT GÉNÉRÉ (8 sections)
────────────────────────────────────────────────────────────────────────────
1. Page de garde         - Identité client, type, date, auditeur
2. Résumé exécutif       - Synthèse pour la direction (IA)
3. Contexte & Périmètre  - Environnement audité
4. Méthodologie          - Standards utilisés (ISO, OWASP, SOC2...)
5. Analyse globale       - Score, matrice des risques, distributions
6. Findings détaillés    - Descriptions enrichies IA, impact métier
7. Plan d'action         - Mesures priorisées avec responsables (IA)
8. Conclusion            - Points positifs, axes d'amélioration (IA)

🚀 DÉMARRAGE RAPIDE
────────────────────────────────────────────────────────────────────────────
1. Installer les dépendances :
   pip install -r requirements.txt

2. Configurer la clé API (.env) :
   OPENAI_API_KEY=sk-...

3. Initialiser la base de données :
   python db/init_db.py

4. Lister les audits :
   python main.py --list-audits

5. Générer un rapport :
   python main.py --audit-id 1 --format pdf
